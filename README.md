# ITMO Course Platform

Современная онлайн-платформа для создания и прохождения курсов.  
Текущая степень готовности: **frontend + архитектурный каркас backend**.

Проект ориентирован на стек:

- HTML / CSS / JavaScript
- Bootstrap 5
- Python / Flask
- SQLite / SQLAlchemy
- GitHub Actions
- Docker (минимальная заготовка)

---

## Что уже есть

- многостраничный интерфейс;
- отдельная страница авторизации / регистрации;
- роли **student** и **teacher** на уровне UI;
- главная страница со списком курсов;
- страница конкретного курса;
- запись на курс в демо-режиме;
- профиль пользователя;
- страница прохождения курса;
- sidebar со списком блоков;
- блок теории;
- блок практики с отправкой решения и демо-вердиктом;
- моковые данные для одного тестового курса;
- архитектурный каркас Flask-приложения;
- проектирование БД;
- CI для ветки `dev`;
- минимальная Docker-заготовка.

---

## Чего пока нет

- реальной авторизации;
- серверной логики регистрации на курсы;
- настоящей проверки решений;
- API;
- админки / кабинета преподавателя;
- истории посылок на UI;
- продакшен-деплоя.
